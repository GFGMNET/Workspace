# Wiki pages that are not published yet

`docs/wiki/` is published to the GitHub wiki on every push, and packed into the app's help (*Help & wiki*) by every release build. Pages for a version that
is **not released yet** wait here, so they don't go online too early (maintainer's decisions 2026-11-20 and 2026-11-23):

- **1.0** (history): its pages were moved into `docs/wiki/` when 1.0 was released on 26 Nov 2026.
- **Later versions:** one folder per version, e.g. `v1.0.2/`. Put new or changed pages for that version
  there (whole pages, same file names as in `docs/wiki/`; a changed `_Sidebar.md` too). The release of that version moves the
  folder's pages into `docs/wiki/` and deletes the folder — then the wiki is published.

Edit wiki text for a coming version here, not in `docs/wiki/`.

1.0.1 is out (26 Nov 2026): its pages are in `docs/wiki/`. There are no waiting pages now.
