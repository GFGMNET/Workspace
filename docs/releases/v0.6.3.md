**The last 0.x version.** It prepares the move to version 1.0 (*Workspace*).

### What is new
- **Ready for 1.0:** when version 1.0 is released, this app offers it like any update. It checks the download first (on Windows the program must be signed), keeps the old program as a backup, and starts Workspace 1.0. Your data stays where it is.
- **Chat:** you can go to another page while Claude answers; the answer keeps coming. *Stop* stops Claude. *Always allow in this chat* counts at once.
- **Project header:** tabs that don't fit go into **More**; *Manage* is a gear icon and holds the project folder (copy path, Claude CLI command, open in VS Code).
- **Explorer:** pictures and downloads open again.
