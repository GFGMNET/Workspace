### New
- **Desktop app:** the Windows and Linux downloads now open the workspace in their own window instead of a browser tab. Node.js and the browser engine are included, so it works the same on every computer, including the VS Code tab. Use **Workspace → Open in browser** or `--browser` if you prefer the browser (#36).
- **Linux servers:** `./project-workspace-server` runs the workspace without a window (#36).

### Improved
- **Updates:** the app now restarts by itself after an update (#35).

### Fixed
- **Claude CLI:** the workspace MCP server is now registered as `project-workspace`, because `workspace` is a reserved name in Claude CLI (#37).

**Linux, coming from v0.5:** download this zip once, unzip it and move your `data` folder into it. Later updates work in the app again.
