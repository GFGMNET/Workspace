# Workspace 1.0

Workspace 1.0 is the same app you know — rebuilt from the ground up. It is smaller (about 6 MB instead of over 100 MB),
starts faster and needs far fewer security updates, because it uses the browser engine that is already on your computer
(WebView2 on Windows, WebKitGTK on Linux). Your projects, your data folder and your files stay exactly as they are.

## In short

#### New
- A new, smaller and faster app (Windows 11 or Linux) — your projects and data stay as they are
- Ticket tab for GLPI 11
- VS Code opens by itself
- Two layouts to choose from, and a choice of tabs per project

#### Changed
- The issues feature is called `issue` — old projects keep working
- The window's X closes the app
- The app is signed: trust the certificate once (see the details)

#### Fixed
- Help & wiki links did nothing
- The VS Code tab was sometimes black or didn't start
- The Issues tab showed up twice; lists had no search bar

#### Security
- Two libraries updated (`url`, `cookie`)

## Before you update

- **Make a backup of your `data` folder** (it holds all your projects). How: wiki [Backup](https://github.com/GFGMNET/Workspace/wiki/Backup).
- **Windows 11 or Linux (x64)** is needed. Linux: Ubuntu 24.04 / Mint 22 / Debian 13 / Fedora 40 or newer. Not supported: Windows 10, macOS, ARM computers (e.g. Raspberry Pi), older Linux (e.g. Ubuntu 22.04, Debian 12).
- **The program is signed** with the project's own certificate "Workspace". Windows shows a warning until you trust it once —
  it takes a minute: wiki [Signing certificate](https://github.com/GFGMNET/Workspace/wiki/Signing-certificate).

## How to update

- **From 0.6.3:** click **Update now** in the bar at the top. The app checks that the download is the real one, keeps your
  `data` folder and starts 1.0. Older 0.x versions first update to 0.6.3, then to 1.0.
- **By hand:** download the zip for your system below, unpack it into a new folder, move your `data` folder next to
  `Workspace.exe` (Linux: `workspace`) and start it.
- More: wiki [Moving to 1.0](https://github.com/GFGMNET/Workspace/wiki/Moving-to-1.0).

## What's new

### Ticket tab (GLPI 11)
See and work on the tickets of your GLPI 11 ticket system right inside a project: read, create, change the text and the
state, add follow-ups and a solution. Above the list you can filter by **Open · Pending · Closed · Solved** — *Open* is
selected when you start (#59, #97).
**How:** add the *Ticket* feature to a project and enter the address of your GLPI and your tokens once (they are kept as
secrets, never in the project). Wiki: [Ticket](https://github.com/GFGMNET/Workspace/wiki/Feature-Ticket).

### VS Code opens by itself
Click **VS Code** in a project and the editor opens inside the app — no *Start* button any more. While it starts, the tab
says *VS Code is starting…*; the very first time this can take up to a minute, because VS Code downloads its web part once.
Only the editor is shown. If VS Code isn't installed, the tab says so and links to the download (#105).
It also starts reliably now: no black window and no "VS Code did not start (port already in use)" (#104).

### Two layouts — choose the one you like
- **Menu left** (as before): projects and links on the left, the features of a project as tabs along the top.
- **Menu top**: the menu as a bar at the top, the projects in a drop-down, and the features of a project as a list on the
  left that you can collapse to icons (**Ctrl+B**).

Switch with the small **layout button** at the bottom of the menu. Next to it, the **light / dark button** switches
*Light → Dark → Auto* (Auto follows Windows). Both are remembered on this PC (#90, #101).
With **more than 4 projects**, *Menu left* shows them in a drop-down instead of a long list (#102).
Wiki: [Desktop app](https://github.com/GFGMNET/Workspace/wiki/Desktop-App).

### Choose which tabs a project shows
The new **Tabs** button next to **+** lets you hide tabs you don't need in a project. Hidden tabs are only hidden — nothing
is deleted (saved as `hide_tabs:` in the project's `project.yaml`) (#89).

### project.yaml in the gear menu
The project's settings file `project.yaml` now opens from the gear (⚙) menu next to the project name (#87).

### More room for the content
The line "… is defined in features/….yaml" above every tab is now hidden behind a small **ⓘ** in the corner. Click it to
see it, together with the Help link (#80).

### Search in lists
Text features with the *list* layout now have a search bar. It finds titles right away and words inside the pages.
`search: false` in the feature file hides the bar — in *list* and *cards* (#108).

### A new wiki
New order — **Home, Getting Started, Features, MCP** — and every feature page starts with *What you need*. New pages:
how to make your own feature (and what a feature can't do), Backup, Moving to 1.0 (#85, #86).

## What changed

- **The issues feature is now called `issue`** (shown as *Issues*), for github.com. Projects that say `feature: github_issue`
  or `feature: github` keep working — you don't have to change anything (#83). After the update it no longer shows up twice (#99).
- GitHub issues: `repo:` may be written in any case, and you can paste the whole address from the browser (#84).
- **Links to websites** (e.g. *Help & wiki*) open in your normal browser (#82, #98).
- **Update window:** shows a short summary of what's new, with a link to all details on GitHub (#117).
- **The window's X closes the app.** It no longer hides in the tray like 0.x did.
- The tray menu lists what is due today; one click opens it. (A reminder notification itself can't be clicked.)
- **Secrets:** on Windows they are taken over from 0.x; on Linux please enter them again once.
- **The old app (0.x) is retired.** It gets no more updates — please move to 1.0.

## Fixed

- *Help & wiki* and other help links did nothing in the desktop app (#82, #98).
- The Issues tab showed up twice after updating (#99).
- VS Code tab: sometimes a black window, sometimes "VS Code did not start" (#104).
- Text features with *list* had no search bar; *cards* ignored `search: false` (#108).

## Security

- Two libraries updated because of known problems: `url` 2.5.9 (RUSTSEC-2026-0592, #106) and `cookie` 0.18.3
  (RUSTSEC-2026-0594, #107).
- From now on every release waits until the security checks are clean.

## Known limits

- Windows 11 and Linux x64 only (no Windows 10, ARM or macOS).
- Linux needs WebKitGTK 4.1 for the window (most desktops have it); `workspace-server` runs without a window.
