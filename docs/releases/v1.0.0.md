**Workspace 1.0** — draft, completed on release day by the scheduled 1.0 check.

### Also in 1.0
- Feature tabs: the line "… is defined in features/….yaml → stores … · layout …" is hidden behind a small ⓘ in the corner, so the content gets the space. A click shows it, with the Help link (#80).
- **Help & wiki** and the other help links open in your browser again (#82).
- The issues feature is now called `issue` (*Issues*). In 1.0 it is for github.com only. Projects that say `feature: github_issue` or `feature: github` keep working (#83).
- GitHub issues: `repo:` may be written in any case, and you can paste the whole address from the browser (#84).
- Wiki: new order — Home, Getting Started, Features, MCP — and every feature page starts with *What you need* (#85, #86).
- **project.yaml** moved into the gear (⚙) menu next to the project name (#87).
- **Tabs** button next to **+**: choose per project which tabs are shown (saved as `hide_tabs:` in project.yaml, #89).
- **Two layouts**: *Menu left* (as before) or *Menu top* — the menu as a bar at the top, the projects in a drop-down, and the features of a project as a list on the left that collapses to icons. Switch in the menu; remembered on this PC (#90).
