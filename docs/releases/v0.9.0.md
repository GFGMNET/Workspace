**Beta of version 1.0 — the app rebuilt in Rust.** This is a pre-release for testing. Installed 0.x apps don't get it.

### What is new
- The app is now a small Rust program. It uses the browser engine of your system (WebView2 on Windows, WebKitGTK on Linux) instead of shipping its own. The download is about 6 MB instead of 157 MB, and far fewer security updates are needed.
- Everything else works as before: the same screens, the same data folder, the same files on disk. Chat with Claude, the VS Code tab, the tray, reminders and start with the computer are all there.
- Secrets are protected by Windows (DPAPI) or by the Linux keyring.
- Updates are checked before they are installed: on Windows the program must be signed, on Linux the checksum must match.

### How to test
1. Make a **copy of your data folder** first.
2. Unzip the package for your computer (`windows-x64` or `linux-x64` / `linux-arm64`) into a new folder.
3. Put the copy of your data folder next to the program, named `data`.
4. Start `ProjectWorkspace.exe` (Windows) or `project-workspace` (Linux).

### Known differences
- This beta is **not signed** yet: Windows SmartScreen will warn. Choose *More info → Run anyway*. The signed version is 0.9.1.
- Clicking a reminder does not open the item yet.
- Secrets saved by the 0.x app on Linux have to be entered again (on Windows they are taken over).
