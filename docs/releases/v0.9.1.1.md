### What is new since 0.9.1
- **Ticket (GLPI):** a project shows its GLPI tickets (category = project name): list, **+** new ticket, read, edit the text, set the state, follow-ups and solution. Setup: wiki page [Ticket](https://github.com/GFGMNET/Workspace/wiki/Feature-Ticket).
- **VS Code tab:** VS Code starts by itself when you open the tab, and only the editor is shown. If VS Code is missing, the tab says so and links to the download.
