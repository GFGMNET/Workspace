### New
- **Manage projects:** rename a project (and its folder, if you like), remove features from it, archive it, or delete it. Archived projects can be restored from the home page (#11).
- **Full YAML:** project.yaml, features and records now support all of YAML: anchors and aliases, `<<:` merge keys, several documents in one file, and more. Files with small mistakes still open, with a warning. Comments in records are kept when you save them from a form (#12).
