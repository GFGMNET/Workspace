First release of **Project Workspace**: one workspace for very different projects, built from YAML, with no database.

### What's in it
- **Projects from YAML:** `project.yaml` says which features a project has, and `features/*.yaml` says what they mean. Add your own feature types without code.
- **Building blocks:** wiki pages, knowledge cards, picture gallery (sort and group by date and album), files, scripts with a code editor, tables, Kanban, calendar, org chart, offline map with pins, Mermaid diagrams, GitHub issues, and chat with Claude CLI.
- **Every project has:**
  - an Overview (counts, coming up, open tasks, recent changes)
  - an Explorer for all its files
  - a VS Code tab with the full VS Code in the app, plus buttons for the desktop VS Code
- **Links between features:** `[[Title]]` links, link fields, and *mentioned in* on every page and record.
- **Claude:**
  - chat runs Claude CLI in the project folder, with permissions set per project (ask / auto / read-only)
  - skills and MCP connections are written where Claude CLI finds them
  - a workspace MCP server lets Claude manage projects from any terminal
- **Projects in an existing folder** (`location:`), so the workspace can even manage itself (example *Workspace (development)*).
- **Your data stays separate** in `data/`. The app checks for new versions once a week and updates with one click, keeping a backup.
- Light and dark mode, a collapsible sidebar, and full-text search.

### Getting started
Unzip, double-click `start.bat` (Windows) or run `./start.sh`. You need Node.js 18 or newer. See the [Getting Started guide](https://github.com/GFGMNET/Workspace/blob/main/docs/GETTING-STARTED.md).
