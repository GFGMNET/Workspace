# Workspace 1.0.1

Many new things in one version: new tabs (Version Control, ComfyUI), Forgejo in the Issues tab, six new layouts for text,
a dashboard on the Overview, the whole help inside the app, the chat with LM Studio, and MCPs for six programs.

## In short

#### New
- Version Control tab: files and history of a Git or SVN repository (read only)
- ComfyUI tab: run your workflows and keep the pictures, videos and audio
- Issues tab also for your own Forgejo server
- Six new layouts for text: journal, book, sticky notes, board, table, blog
- Dashboard on the Overview of each project
- Help & wiki inside the app, also without internet
- Chat with a local model in LM Studio
- MCPs for Blender, Unity, Unreal Engine, Godot, OpenSCAD and FreeCAD
- Restore deleted built-in features

#### Changed
- The Gallery shows and plays videos and audio too
- `dashboard` is now a project setting — a feature of your own with that name can't be a tab any more

## Before you update

- **Make a backup of your `data` folder.** How: wiki [Backup](https://github.com/GFGMNET/Workspace/wiki/Backup).
- Only if you made a feature of your own called **`dashboard`**: rename it (key in `project.yaml` and file in `data/features/`), because `dashboard:` is now the project's dashboard.

## How to update

Click **Update now** in the bar at the top of the app (it checks once a week). By hand: download the zip below, unpack it and
replace everything **except the `data` folder**.

## What's new

### Version Control
A tab that shows the files and the history of a Git or SVN repository — on your own server or in the network. Read only:
nothing is changed in the repository. **Files** shows the folders and files and the last change of a file; **History** shows
every change with message, files, author and date; **History of this file** shows only that file.
**How:** **+ Feature → Version Control**, then in `project.yaml`:
```yaml
version-control:
  type: git                      # git or svn
  protocol: https                # git: http, https or ssh · svn: svn, http or https
  server: 192.168.1.20
  port: 3000
  path: team/project.git
  user: alice
  password: ${secret:git-pass}   # or for ssh:  key: ${secret:git-key}
```
Save the password (or ssh key) under **Settings → Secrets**. You need Git (or SVN) installed.
Wiki: [Version Control](https://github.com/GFGMNET/Workspace/wiki/Feature-Version-Control) (#60)

### ComfyUI
A tab that runs your ComfyUI workflows. Upload a workflow (saved in ComfyUI with **Export (API)**), label it picture, video
or audio, change the positive and negative text, click **Run**. The results are saved in the Gallery's album
**KI_Pictures** (or in `comfyui/results/` when the project has no Gallery).
**How:** **+ Feature → ComfyUI**, then in `project.yaml`: `comfyui: { url: http://127.0.0.1:8188 }`.
Wiki: [ComfyUI](https://github.com/GFGMNET/Workspace/wiki/Feature-ComfyUI) (#93)

### Forgejo in the Issues tab
The Issues tab can read the issues of a repository on your own Forgejo server.
**How:** in `project.yaml`:
```yaml
issue:
  engine: forgejo
  url: https://192.168.1.20:3000
  repo: team/app
  token: ${secret:forgejo-token}   # only for private repositories
```
Wiki: [Issues](https://github.com/GFGMNET/Workspace/wiki/Feature-Issues) (#96)

### Six new layouts for text
Pages can now also be shown as a **journal** (by date), a **book** (chapters, contents, full screen), **sticky notes**,
a **board** (columns), a **table** (with columns from the pages' settings) or a **blog**.
**How:** **Features → (a feature that keeps pages) → Layout**, or `layout: journal` in the feature file.
Wiki: [Journal](https://github.com/GFGMNET/Workspace/wiki/Layout-Journal) · [Book](https://github.com/GFGMNET/Workspace/wiki/Layout-Book) ·
[Sticky notes](https://github.com/GFGMNET/Workspace/wiki/Layout-Sticky-notes) · [Board](https://github.com/GFGMNET/Workspace/wiki/Layout-Board) ·
[Table](https://github.com/GFGMNET/Workspace/wiki/Layout-Table) · [Blog](https://github.com/GFGMNET/Workspace/wiki/Layout-Blog) (#116)

### Dashboard on the Overview
Each project's Overview can have its own dashboard. **How:** open the **Overview**, click **Edit**, **Add block**: choose a
feature of the project, show it as a number or a list, add a filter (e.g. `state=open`) if you like. Drag a block onto
another one to move it, drag its corner to change the size, then **Save**. It is kept in `project.yaml` under `dashboard:`.
Wiki: [Dashboard](https://github.com/GFGMNET/Workspace/wiki/Dashboard) (#115)

### Help & wiki inside the app
All wiki pages are now inside the app, with a search, also without internet. **Help** is in the side bar. The **(i)** next
to a feature shows a short line; a click opens its page in a side panel.
Wiki: [Help inside the app](https://github.com/GFGMNET/Workspace/wiki/Help) (#95)

### Chat with LM Studio
The chat can use a model that runs on your own PC in [LM Studio](https://lmstudio.ai/) instead of Claude. It reads and
changes the project's files and asks first, like Claude (`permissions: ask | auto | read-only`).
**How:** start the LM Studio server and load a model, then in `project.yaml`:
```yaml
chat:
  engine: lmstudio
  model: qwen2.5-coder-7b-instruct
```
Wiki: [Chat](https://github.com/GFGMNET/Workspace/wiki/Feature-Chat) (#94)

### MCPs for programs
Claude in the chat can work with **Blender, Unity, Unreal Engine, Godot, OpenSCAD and FreeCAD**. What it makes is saved in
the project, in the folder named after the program (`blender/`, `godot/`, …).
**How:** gear (⚙) → **Manage → MCP**, tick the programs (or `programs: [blender]` in `project.yaml`). Each program needs its
own small add-on — the wiki page of each program says what and how.
Wiki: [MCP](https://github.com/GFGMNET/Workspace/wiki/MCP) · [Blender](https://github.com/GFGMNET/Workspace/wiki/MCP-Blender) ·
[Unity](https://github.com/GFGMNET/Workspace/wiki/MCP-Unity) · [Unreal Engine](https://github.com/GFGMNET/Workspace/wiki/MCP-Unreal) ·
[Godot](https://github.com/GFGMNET/Workspace/wiki/MCP-Godot) · [OpenSCAD](https://github.com/GFGMNET/Workspace/wiki/MCP-OpenSCAD) ·
[FreeCAD](https://github.com/GFGMNET/Workspace/wiki/MCP-FreeCAD) (#109–#114)

### Restore and update built-in features
**Features → Restore built-in features** brings back a built-in feature you deleted. When a new version of the app brings a
new version of a built-in feature, the app tells you at the start; a tab that still uses the old one shows
**Use the new version** (its own settings stay).
Wiki: [Features](https://github.com/GFGMNET/Workspace/wiki/Features) (#100)

## What changed

- The **Gallery** also shows videos and audio files and plays them when you click one — nothing to do.
- `dashboard` is a project setting now (see *Before you update*).
- The old 0.x app (Electron) was removed from the repository (#125) — nothing to do.

## Known limits

- Version Control only reads; writing and pushing will come with a later version.
- ComfyUI: only workflows saved with **Export (API)** can be run.
- LM Studio: small models can be slow and sometimes don't use the tools well.
