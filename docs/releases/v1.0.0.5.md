**VS Code opens by itself.**

### What is new
- Click **VS Code** in a project: the editor opens inside the app right away — no *Start* button. While it starts, the tab says *VS Code is starting…* (the very first time this can take up to a minute, because VS Code downloads its web part once).
- The tab shows only the editor; the row of buttons above it is gone.
- If VS Code is not installed, the tab says so and links to the download.
