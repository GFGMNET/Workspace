**Version 1.0 (Rust), signed.** A pre-release: installed 0.x apps don't get it.

### What is new since the betas
- The Windows program is **signed** (SignPath Foundation), so Windows SmartScreen no longer warns.
- The app is now called **Workspace** everywhere: window, tray, notifications, the program (`Workspace.exe`, `workspace` on Linux) and the downloads (`workspace-v0.9.1-…zip`).
- The tray menu lists what is due today; one click opens the item.
- Security: newer zip library (fixes known problems when unpacking updates), a maintained date library, and a check of all Rust libraries on every change and every week.
