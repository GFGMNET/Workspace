**Second beta of version 1.0 (Rust).** A pre-release for testing; installed 0.x apps don't get it.

### Fixed after the first test
- **X closes the app.** Reminders work while the app is running (and when it starts with the computer, until you open and close the window).
- The app no longer opens a 0.x app that is still running in the tray (with its data). If another workspace uses the port, it takes the next free one.
- The Claude CLI check no longer drops out when you switch projects.
- Project header: tabs that don't fit go into a **More** menu. The buttons *Claude CLI*, *VS Code* and *Copy path* are gone; *Manage* is now a gear icon, and inside it you find the folder with *Copy path*, *Copy Claude CLI command* and *Open in VS Code*.

### How to test
Same as 0.9.0: copy your data folder, unzip into a **new** folder, put the copy next to the program as `data`, start `ProjectWorkspace.exe`. Quit a running 0.x app first (tray → Quit) to be safe.

Not signed yet: Windows SmartScreen warns — *More info → Run anyway*.
